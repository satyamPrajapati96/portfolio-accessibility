# Accessible Personal Portfolio Website

A multi-page personal portfolio website built using semantic HTML5 and CSS, with a focus on accessibility, responsive design, and SEO.

## 📌 Project Overview

This project was created as part of the **HTML5 Semantic Structure & Accessibility** task.

The website follows modern HTML5 semantic standards and includes accessibility features to provide a better experience for keyboard and screen-reader users.

## ✨ Features

- Multi-page personal portfolio
- Semantic HTML5 structure
- Accessible navigation
- ARIA labels and attributes
- Keyboard-friendly navigation
- Accessible contact form
- Proper form labels and validation
- SEO-friendly meta tags
- Responsive design
- Visible keyboard focus states
- Lighthouse optimized

## 📄 Pages

- **Home** – Introduction and skills
- **About** – Personal and educational information
- **Projects** – Featured development projects
- **Contact** – Accessible contact form

## 🛠️ Technologies Used

- HTML5
- CSS3
- Semantic HTML
- ARIA
- Responsive Web Design
- SEO Best Practices

## ♿ Accessibility

The project includes accessibility-focused practices such as:

- Semantic HTML elements
- Proper heading hierarchy
- ARIA labels where appropriate
- Labels associated with form controls
- Keyboard navigation support
- Visible focus indicators
- Accessible form controls
